# Правки к сайту DINSBURGH (точное ТЗ для AI-агента)

Ниже — перечень правок в виде однозначных требований и критериев приемки (Acceptance).  
Цель — быстро внести изменения без интерпретаций.

---

## 1) Header: текст, позиционирование, типографика

**Нужно:**
- Текст в header должен быть **строго**: `DINSBURGH`
- **По центру** (горизонтально) внутри header
- **UPPERCASE** (верхний регистр)
- Шрифт: **Helvetica** (fallback: `Arial, sans-serif`)
- Убедись, что нигде в header не используется `dinburgh` / `dinsburgh` / `Dinburgh`.

**Acceptance:**
- Визуально в центре на всех ширинах (mobile/tablet/desktop).
- Всегда `DINSBURGH`, Helvetica.

---

## 2) Удалить текст “Портфолио художника”

**Нужно:**
- Полностью убрать **все вхождения** текста: `Портфолио художника`
- Не оставлять пустые отступы/“дыры” в макете после удаления (пересобрать spacing).

**Acceptance:**
- На странице нет текста `Портфолио художника` ни в одном месте.

---

## 3) Никнейм в верхней части блока портфолио

> Ранее было “под текстом ‘Портфолио художника’…”, но этот текст удаляется (см. п.2).  
> Поэтому фиксируем итоговое поведение без двусмысленности.

**Нужно:**
- В верхней части блока портфолио (hero-зона портфолио, **над** переключателями разделов) показать никнейм:
  - Текст: `DINSBURGH`
  - Стиль **идентичен header**: центр, uppercase, Helvetica, максимально близкие вес/трекинг/размер.
- Никаких дополнительных заголовков типа “Портфолио художника” не должно быть.

**Acceptance:**
- В блоке портфолио сверху есть `DINSBURGH`, совпадающий по стилю с header.

---

## 4) Блок портфолио: удалить лишние тексты, добавить описание раздела, плашку “PORTFOLIO”, центрирование, сетка 3×3

### 4.1 Удалить тексты

**Нужно:**
- Полностью убрать **все вхождения** текста: `Портфолио`
- Полностью убрать текст:  
  `Избранные работы сгруппированы по направлениям. Нажмите на карточку, чтобы увидеть работу в деталях.`

**Acceptance:**
- На странице отсутствуют указанные тексты.

### 4.2 Описание выбранного раздела (новое поведение)

**Нужно:**
- Под кнопками/табами подразделов портфолио добавить **текстовое описание** выбранного раздела (skills/навыки/о направлении).
- Описание должно **меняться при смене таба**.
- По умолчанию выбран **самый левый таб** → при загрузке показывается описание **левого** раздела.

**Acceptance:**
- При переключении табов меняются:
  1) контент сетки работ
  2) текст описания раздела

### 4.3 Плашка “PORTFOLIO” как header

**Нужно:**
- Ниже текста описания выбранного раздела вставить плашку/полосу с текстом:
  - `PORTFOLIO` (строго uppercase)
- Плашка должна выглядеть **как header** (glass/blur/тонкая рамка/паддинги/высота визуально аналогичны).
- Плашка — визуальный разделитель перед сеткой карточек.

**Acceptance:**
- Плашка `PORTFOLIO` визуально считывается как “второй header” внутри секции портфолио.

### 4.4 Центрирование табов и карточек

**Нужно:**
- Кнопки/табы переключения подразделов портфолио — **по центру**.
- Контейнер сетки карточек — **по центру**.
- Карточки в сетке визуально центрированы относительно контейнера (без смещения влево).

**Acceptance:**
- На desktop сетка и табы выглядят симметрично и центрировано.

### 4.5 Сетка карточек 3×3

**Нужно:**
- Desktop: **3 колонки** (3×3 при наличии 9 работ).
- Если работ > 9 — продолжать ниже (следующие строки по 3).
- Допускается адаптив:
  - tablet: 2–3 колонки
  - phone: 1 колонка
- Важно: на desktop — **строго 3 колонки**.

**Acceptance:**
- На desktop стабильно 3 колонки, ровные отступы (gap), сетка не “прилипает” к левому краю.

## 5) Цветовая температура: сделать сайт теплее на +50%

**Цель:** вся визуальная палитра сайта должна выглядеть заметно теплее (менее “холодно-серой”), при сохранении “темности” и контраста.

**Нужно:**
- Повысить “теплоту” цветов всего сайта на **~50%** по субъективной шкале (воспринимаемое потепление: серые уходят в теплые, белый — в слегка кремовый, акценты — чуть теплее, без выгорания и потери контраста).

### Способ реализации (выбери один, зафиксируй в коде и README)

**Вариант A (рекомендуемый, контролируемый):**  
Скорректировать базовые переменные темы:
- Заменить холодные gray/white на **теплые нейтрали** (например, белый ближе к теплому, серые с небольшим red/yellow bias).
- Акцент `#FFFFDC` использовать как мягкий “теплый белый” для подсветок/бликов стекла.
- Убедиться, что фон остаётся темным, а контраст текста соответствует accessibility.

**Вариант B (быстро, но менее точно):**  
Глобальный CSS-filter на корневом контейнере (например, `html` или `body`) для потепления:
- Использовать комбинацию `sepia()` + лёгкая корректировка `hue-rotate()` и `saturate()` / `contrast()`.
- Важно: не допускать “грязи” на изображениях работ и сильного искажения акцентных цветов.  
  Если изображения искажаются — применить фильтр только к UI-слоям, а изображения исключить.

**Acceptance:**
- Визуально сайт ощутимо теплее, чем было, примерно на “+50%”, без потери читаемости.
- Текст остается контрастным, фон — темным.
- Акцентные цвета не “ломаются” (особенно `#FF4500`).
